An entry for [Make the best national statistics site](https://make.fun/bounty/best-national-statistics-site-20261126-0539) — a working, fully offline national statistics site for Indonesia, vintage 2024.

## What it is

Eight pages of verified Indonesian statistics — GDP, population, trade, prices, welfare and regions — with 26 hand-rolled inline-SVG charts, 8 headline KPIs, and nine working controls: a year filter (2019–2024), tabs, sortable tables, live search, Chart ↔ Table toggles, hover tooltips, hash routing, a light/dark theme, and synchronous rendering.

Headline figures (all verified): nominal GDP Rp22,139 trillion, real growth 5.03%, population 281.6 million, inflation 1.57%, unemployment 4.91%, exports US$264.7 bn, and poverty at 8.57% — the lowest since records began in 1960.

## Run it

```sh
node serve.ts        # serves app/ at http://localhost:8080
```

Or open `app/index.html` directly in any browser. No build step, no network requests: no CDN, no webfonts, no analytics, no external images. All charts are inline SVG generated by `app/js/charts.js` from the static data in `app/js/data.js`.

## Structure

- `app/index.html` — Dashboard: 8 KPI tiles, 4 charts, year-by-year table
- `app/economy.html` — GDP & growth, nominal/real tabs, 13 sectors
- `app/trade.html` — Exports, imports and balance tabs; top 10 commodities & partners
- `app/population.html` — Population 2010–2024, provinces, island groups
- `app/regions.html` — GRDP, GRDP per capita, UMP 2025, population-vs-GRDP scatter
- `app/prices-money.html` — Inflation, BI-Rate, rupiah, FX reserves
- `app/social.html` — HDI, Gini, poverty, provincial HDI top/bottom 10
- `app/about.html` — Sources, data vintage, units, definitions, 38-province coverage
- `app/css/style.css` — one stylesheet, CSS variables for the light/dark theme
- `app/js/data.js` — every figure on the site, one source of truth
- `app/js/charts.js` — hand-rolled SVG chart generators (line, area, column, bar, donut, scatter)
- `app/js/app.js` — year filter, tabs, sorting, search, tooltips, hash routing, theme

## Sources

BPS (Statistics Indonesia), Bank Indonesia, Ministry of Manpower (Permenaker No. 16/2024), World Bank, IMF, CIA World Factbook. Data vintage 2024; the minimum wage is 2025 and is labelled as such. See `app/about.html` for the full data dictionary.
